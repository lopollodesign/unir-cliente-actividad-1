      SOBRE EL PROYECTO

      Cómo funciona

      Datos y ejecución

      La página consulta api.php con fetch y async/await. La API devuelve 25 Pokémon, su precio, tipo, imagen y stock; cinco están agotados. Las tarjetas se crean desde JavaScript y se estilizan con Tailwind.

      Para abrirla, ejecuta php -S localhost:8007 en esta carpeta y visita http://localhost:8007.

      El carrito limita las unidades al stock disponible y actualiza el total al añadir, cambiar la cantidad o quitar un producto. Su contenido solo se conserva mientras la página está abierta.

      Funciones y clase ShoppingCart

      ShoppingCart.constructor():
      guarda los productos y la moneda recibidos de la API.
      updateQuantity():
      añade, cambia o elimina unidades, respetando el stock.
      getProductInfo():
      devuelve los datos y las unidades de un producto.
      getCart():
      devuelve los productos seleccionados, la moneda y el total.
      formatPrice():
      muestra el precio con dos decimales y el símbolo de la moneda.
      createCartItem():
      crea un producto del carrito y su selector de unidades.
      updateAddButtons():
      desactiva Añadir cuando se alcanza el stock.
      renderCart():
      redibuja el carrito, sus contadores y el total.
      addProductToCart():
      suma una unidad al carrito.
      addProductToCatalog():
      crea una tarjeta para cada producto del catálogo.
      loadProducts():
      consulta la API, prepara el carrito y carga el catálogo.
